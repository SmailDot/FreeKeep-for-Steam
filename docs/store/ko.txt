Steam의 기간 한정 무료 게임과 DLC를 브라우저에 로그인된 Steam 계정으로 백그라운드에서 자동으로 받습니다. 비밀번호 불필요, 로그인 정보 읽기 없음, 서버 없음.

🔒 안전한 이유
• 브라우저 로그인 활용: Steam에 로그인되어 있으면 브라우저가 Steam 상점 요청에 로그인 정보를 자동으로 첨부합니다. FreeKeep은 "계정에 추가" 버튼과 동일한 요청만 보냅니다.
• 로그인 정보를 읽을 수 없음: Steam 로그인 쿠키는 HttpOnly로 보호되어 확장 프로그램이 읽을 수 없으며, FreeKeep은 쿠키 권한도 요청하지 않습니다.
• 서버 없음: FreeKeep에는 백엔드가 없으며 어떤 데이터도 업로드하거나 수집하지 않습니다.
• 직접 확인 가능: Chrome 확장 프로그램의 "세부정보" 페이지에는 알림과 Steam 상점 접근 권한만 표시됩니다. 소스 코드는 공개되어 있습니다.

많은 자동 수령 도구 vs FreeKeep
❌ 비밀번호나 로그인 정보 필요 → ✅ 전혀 필요 없음
❌ 게임마다 상점 탭을 엶 → ✅ 백그라운드 요청 한 번, 탭 없음
❌ 서버나 봇에서 실행 → ✅ 내 브라우저 안에서만 실행
❌ 개발자 서버로 데이터 전송 → ✅ 서버 없음, 분석 없음, 추적 없음

주요 기능
• 진짜 기간 한정 무료(free to keep)만 받으며, 데모·플레이테스트·무료 플레이 게임은 제외
• 이미 보유한 게임은 건너뛰고, DLC는 본편을 보유한 경우에만 받음
• 내 Steam 상점 지역을 기준으로 판단해 해당 지역의 무료 게임만 받음
• 1·3·6·12·24시간마다, 그리고 브라우저 시작 시 확인
• 자동으로 받거나, 먼저 알림을 받고 직접 결정 가능
• 게임을 받았거나 확인이 필요할 때만 알림
• 선택 기능 Epic Games Store 알림: Epic의 무료 게임을 알려 주며, 받기는 Epic 사이트에서 진행합니다. 기본값은 꺼짐이며 공개 목록 조회에 로그인이 필요 없습니다
• 12개 언어, 코드 약 40 KB, 외부 의존성 없음

이 브라우저에서 Steam 상점에 로그인하면 FreeKeep이 자동으로 동작합니다.

Valve Corporation 및 Epic Games와 관련이 없습니다. Steam은 Valve Corporation의 상표입니다.
