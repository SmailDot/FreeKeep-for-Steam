Steam의 기간 한정 무료 게임과 DLC를 브라우저에 이미 로그인된 Steam 계정으로 백그라운드에서 자동으로 받아 줍니다. 비밀번호 불필요, 쿠키에 손대지 않음, 서버 없음.

🔒 왜 안전한가요? (쉬운 설명)
• 브라우저는 이미 내가 Steam에 로그인했다는 것을 알고 있습니다. store.steampowered.com 으로 가는 요청에는 상점을 둘러볼 때처럼 로그인 정보를 스스로 붙입니다. FreeKeep은 Steam의 "계정에 추가" 버튼과 똑같은 요청을 보내 달라고 브라우저에 부탁할 뿐입니다.
• FreeKeep은 로그인 정보를 볼 수 없습니다. Steam은 이를 어떤 확장 프로그램도 읽을 수 없는 잠긴 쿠키(HttpOnly)에 보관하며, FreeKeep에는 쿠키 권한조차 없습니다.
• FreeKeep 서버는 없습니다. 아무것도 업로드하지 않으니 유출될 것도 없습니다.
• 직접 확인하세요: chrome://extensions → FreeKeep → "세부정보"에는 알림과 store.steampowered.com만 표시됩니다. 코드는 오픈 소스입니다.

많은 자동 수령 도구 vs FreeKeep
❌ 비밀번호, 토큰, 쿠키를 요구 → ✅ 절대 요구하지 않음
❌ 게임마다 상점 탭을 열고 대신 클릭 → ✅ 조용한 백그라운드 요청 한 번, 탭 없음
❌ 서버나 봇에서 실행 → ✅ 내 브라우저 안에서만 실행
❌ 데이터를 자체 서버로 전송 → ✅ 서버 없음, 분석 없음, 추적 없음

기능
• 진짜 기간 한정 무료(free to keep)만 받으며, 데모·플레이테스트·부분 유료 게임은 받지 않음
• 이미 가진 게임은 건너뛰고, DLC는 본편을 가지고 있을 때만 받음
• 1·3·6·12·24시간마다 확인하고, 브라우저를 시작할 때도 확인
• 자동으로 받거나, 먼저 알림을 받고 직접 결정 가능
• 받았거나 확인이 필요할 때만 조용히 한 번 알림
• 선택 기능 Epic Games Store 알림: Epic이 게임을 무료로 풀면 알려 주고, 받기는 Epic 사이트에서 직접 합니다. 기본값은 꺼짐이며 로그인 없이 공개 목록만 읽습니다
• 12개 언어, 코드 약 40 KB, 의존성 없음

이 브라우저에서 Steam 상점에 로그인하면 나머지는 FreeKeep이 알아서 합니다.

Valve Corporation 및 Epic Games와 관련이 없습니다. Steam은 Valve Corporation의 상표입니다.
